# LightMD — 轻量化本地 Markdown 阅读与编辑软件

单文件原生 Windows 桌面程序（仅 ~6.6 MB，无需安装，零外部依赖，复用系统内置 WebView2 引擎），打开即读、随时切换编辑。

## 快速开始

1. **安装为 Windows 桌面应用（推荐）**：
   - 双击运行 `安装为桌面应用.bat`（或在软件内点击 **「安装为桌面应用」**）。
   - 安装后会在 **桌面** 和 **开始菜单** 生成 LightMD 应用图标，注册到 Windows **「设置 → 应用」**（支持随时卸载），并在文件夹右键菜单中添加 **「新建 → Markdown 文档」**。
2. **设置双击 `.md` 直接打开**：
   - 安装时会自动注册 `.md` / `.markdown` 打开方式。如果此前已将 `.md` 设为 VS Code / 记事本等其他程序默认打开（Windows 10/11 会锁定默认应用），只需做最后一步：**右键任意 `.md` 文件 → 打开方式 → 选择其他应用 → 选择 LightMD → 点击「始终」**。
   - 如需卸载，在 Windows「设置 → 应用」中卸载 LightMD，或运行 `卸载桌面应用.bat`。

## 主要功能

- **三种视图一键切换**：**阅读** (`Ctrl+1`) / **分屏实时预览** (`Ctrl+2` 或 `Ctrl+E`) / **纯编辑** (`Ctrl+3`)，分屏支持双向同步滚动。
- **清爽阅读体验**：专为中英文混排优化的排版与表格样式；支持**浅色 / 护眼暖纸 / 暗色**三套主题、字号缩放 (`Ctrl+=`/`Ctrl+-`) 与宽屏模式。
- **文档内跳转与导航**：
  - 点击文档中的相对 `.md` 链接（如 `[01_Education.md](./01_Education.md)`）直接在软件内打开，支持 `Alt+←` 返回上一篇。
  - 左侧可折叠侧边栏 (`Ctrl+\`)：支持**自动目录大纲 (TOC)** 与**同目录 `.md` 文件快速切换**。
  - 支持渲染相对路径本地图片、代码块高亮与一键复制、阅读模式下直接勾选 `- [ ]` 待办项。
- **Word 般文档体验**：默认开启纸张页面视图；支持一键 **导出 Word (.doc)**、**导出 HTML** 与 **打印 / 存为 PDF** (`Ctrl+P`)。
- **高效编辑**：常用格式快捷栏、`Tab/Shift+Tab` 缩进、回车自动续写列表、`Ctrl+S` 保存、`Ctrl+F` 页内查找、自动检测文件外部修改。

